# i18n — Internacionalización

## Overview

Sistema de internacionalización con detección automática de idioma, traducciones por locale, y overrides admin. Usa Project Fluent (100% Rust).

**Base path:** `/api/v1`
**Auth:** No requerida (excepto admin endpoints)

---

## Data Models

### Locale
```json
{
  "code": "string (ej: es, en, pt)",
  "name": "string",
  "native": "string",
  "dir": "string (ltr|rtl)",
  "rtl": "bool"
}
```

---

## Endpoints

### GET /i18n/locales — Listar idiomas disponibles

- **Auth:** No requerida
- **Response 200:**
```json
{
  "default": "es",
  "locales": ["Locale[]"]
}
```

---

### GET /i18n/detect — Detectar idioma del cliente

- **Auth:** No requerida
- **Reglas:** usa header `Accept-Language`
- **Response 200:**
```json
{
  "code": "string",
  "name": "string",
  "native": "string",
  "dir": "ltr|rtl",
  "rtl": "bool",
  "accept_language": "string"
}
```

---

### GET /i18n/translations — Catálogo completo de traducciones

- **Auth:** No requerida
- **Query:** `?locale=es` (default: es)
- **Response 200:**
```json
{
  "locale": "string",
  "dir": "ltr|rtl",
  "rtl": "bool",
  "messages": "object (key-value pairs)"
}
```

---

### GET /i18n/translate — Traducir una key

- **Auth:** No requerida
- **Query:**
  - `locale` (default: es)
  - `key` (requerido)
  - `n` (opcional, para pluralización)
  - `year` (opcional, para interpolación)
- **Response 200:**
```json
{
  "locale": "string",
  "key": "string",
  "value": "string (traducción resuelta)",
  "resolved": "bool"
}
```

---

## Admin Endpoints

### GET /admin/i18n — Listar overrides

- **Auth:** Admin
- **Response 200:**
```json
{
  "locales": ["string[]"],
  "keys": ["string[]"],
  "overrides": "object"
}
```

### POST /admin/i18n — Crear/actualizar override

- **Auth:** Admin
- **Request:**
```json
{
  "locale": "string (debe existir)",
  "key": "string",
  "value": "string"
}
```
- **Response 200:**
```json
{
  "locale": "string",
  "key": "string",
  "value": "string"
}
```

### DELETE /admin/i18n/{locale}/{key} — Eliminar override

- **Auth:** Admin
- **Response 200:** `{ "removed": "bool" }`

---

## Locale Detection Flow

```
Client request
  → Accept-Language header
  → fluent-langneg negotiation
  → Si locale soportado → usarlo
  → Si no → fallback a "es"
```

---

## Dependencies

- **fluent + fluent-langneg:** motor de traducción
- **Config:** default locale
